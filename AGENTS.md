## Project Overview

**Roastory** is a library-cafe management system for Fundacion Universitaria Konrad Lorenz. It is the final project for the "Nuevas Tecnologias de Desarrollo" (NTD) course, developed by the K-Forge team.

## Status

- **Phase:** Early development — stack and architecture under definition with the professor.
- **Delivery:** End of semester (NTD course final project).

## Planned Features

| Module | Description |
|--------|-------------|
| Product catalog | Books, beverages, food with search and filters |
| Inventory management | Stock control and reorder alerts |
| Point of sale | Sales recording and totals calculation |
| Customer management | Customer registry and purchase history |
| Reports | Sales by period and best-selling products |

## Conventions

- **Commits:** `type: message in english` — Conventional Commits, lowercase, no scope, no final period.
- **Branches:** Git Flow (`main`, `develop`, `feature/*`, `chore/*`, `bugfix/*`, `hotfix/*`, `release/*`).
- **Documentation:** Spanish for user-facing docs. English for technical/agent docs.

## AI Agent Instructions

- Do not assume a tech stack until it is explicitly defined in the README or codebase.
- Check README.md and CONTRIBUTING.md before making structural changes.
- Never hardcode credentials or sensitive data.
- Limit changes to the requested scope.
